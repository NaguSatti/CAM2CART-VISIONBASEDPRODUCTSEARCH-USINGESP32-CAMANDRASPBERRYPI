# CAM2CART-VISIONBASEDPRODUCTSEARCH-USINGESP32-CAMANDRASPBERRYPI
Developed a vision-based smart retail system using ESP32-CAM and Raspberry Pi for real-time product identification and automated product search.
The system captures product images using ESP32-CAM, processes them on Raspberry Pi using OpenCV and Pytesseract OCR, and retrieves product information automatically.
Implemented wireless communication between hardware modules and integrated image processing, OCR, and QR code generation for intelligent retail automation.
Technologies Used:
•Python
•OpenCV
•ESP32-CAM
•Raspberry Pi
•Pytesseract OCR
•IoT
•Computer Vision
•Wi-Fi Communication
